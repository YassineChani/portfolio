# Portfolio - Yassine Chani 🚀

Portfolio professionnel moderne, minimaliste et responsive de **Yassine Chani** — Expert en Développement Web Full Stack & Intelligence Artificielle.

## 🌟 Aperçu & Fonctionnalités

- **Design Minimaliste & Moderne** : Conçu avec une typographie soignée et un agencement épuré.
- **Dark Mode / Light Mode** : Basculement automatique et persistance du thème avec `localStorage`.
- **Responsive Design** : Adapté pour mobiles, tablettes et ordinateurs de bureau (Desktop).
- **Sections Complètes** :
  - **Hero** : Présentation percutante et photo de profil intégrée.
  - **À Propos** : Formations académiques (EHEI, Prépa, Bac), langues et soft skills.
  - **Expériences Professionnelles** : Gloria (USA), Enseignement Web & IA, Freelance Canada, etc.
  - **Compétences & Stack** : Badges interactifs (Front-End, Back-End, AI/ML, Cloud & DevOps, DB, MLOps).
  - **Projets Réalisés** : Projets clés issus de GitHub avec filtres dynamiques (Web, SaaS, IA).
  - **Contact** : Formulaire interactif et coordonnées directes (Email, WhatsApp).

## 🛠️ Technologies Utilisées

- **HTML5** sémantique
- **Tailwind CSS** (via CDN & styles sur-mesure)
- **JavaScript (ES6+)** pour les interactions et filtres dynamiques
- **Google Fonts** (Plus Jakarta Sans & Space Grotesk)

## 💻 Déploiement Local

Pour lancer le projet en local :

```bash
# Avec Python
python -m http.server 3000

# Ou simplement en ouvrant index.html dans votre navigateur
```

Accédez à `http://localhost:3000`.
